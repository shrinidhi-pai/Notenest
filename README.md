📝 Project Overview

Notes Keeper App is a simple web application that allows users to create, edit, delete, and manage personal notes easily. The application is designed with a clean and responsive interface using only HTML, CSS, and JavaScript.

It helps users organize important information digitally and access notes quickly whenever needed.

🚀 Features
➕ Add New Notes
✏️ Edit Existing Notes
❌ Delete Notes
💾 Save Notes Instantly
🔎 Search Notes by Keywords
📋 Display All Notes
📱 Responsive User Interface
🌙 Simple and Attractive Design
🛠️ Technologies Used
Technology	Purpose
HTML5	Structure of the application
CSS3	Styling and responsive design
JavaScript	Application functionality and note management
